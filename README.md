# Vision Control

Приложение для Windows: жесты руки и взгляд с веб-камеры. Действия назначаются списками, без правки кода.

## Запуск

1. Дважды откройте `Запуск.bat` (нужен Python 3.12).
2. Разрешите доступ к камере.
3. Вкладка **Руки** — жесты. Вкладка **Глаза** — взгляд и моргание.
4. Слева окно отладки. Справа каждому триггеру выберите действие.
5. Переключатель **Действия включены** — пауза, чтобы не кликать по самому приложению. Пока курсор над окном программы, действия тоже не срабатывают.

## По умолчанию

- Указательный палец — движение курсора
- Пинч — левый клик
- Левый глаз — ЛКМ, правый глаз — ПКМ
- Оба глаза — двойной клик

Для управления мышью взглядом на вкладке «Глаза» у пункта **Взгляд (курсор)** выберите «Двигать курсор».
